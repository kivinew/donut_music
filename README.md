# Donut Music 🍩🎵

Анимированный 3D-пончик (donut) в консоли с музыкальным сопровождением. Проект создан как поздравление для Дмитрия со вступлением в коллектив 2 линии!

## Описание

Этот проект визуализирует классический анимированный пончик в терминале с использованием символов ASCII и цветовой палитры. Анимация сопровождается фоновой музыкой.

### Особенности

- 🎨 Несколько цветовых палитр для визуализации
- 🔄 Переключение 3D-фигур: бублик, солнечная система, танцующая девушка из `girl.py`, куб, сердце и галактика
- 🔍 Возможность масштабирования (зум/отдаление)
- 🎵 Встроенное музыкальное сопровождение
- 💻 Кроссплатформенность (Windows, Linux, macOS)

## Установка

Для установки проекта требуется [uv](https://github.com/astral-sh/uv) — быстрый пакетный менеджер для Python.

```bash
uv sync
```

## Запуск

```bash
uv run main.py
```

## Управление

| Клавиша | Действие |
|---------|----------|
| `←` / `→` | Переключение цветовой палитры |
| `+` / `↑` / `W` | Приблизить (увеличить зум) |
| `-` / `↓` / `S` | Отдалить (уменьшить зум) |
| `0` | Сбросить зум |
| `N` / `X` | Переключить 3D-фигуру вперёд / назад |
| `M` | Выключить музыку |
| `Q` / `Esc` | Выход |

## Требования

- Python 3.12+
- Зависимости:
  - `colorama` — кроссплатформенная поддержка цветов в консоли
  - `pygame-ce` — воспроизведение музыки
  - `pyinstaller` — сборка исполняемого файла (опционально)

## Сборка исполняемого файла (опционально)

```bash
PyInstaller main.py
```

## Структура проекта

``` text
donut_music/
├── donut_c/                        # Модуль с реализацией на Си
│   └── donut_renderer.c            # Исходный код рендера пончика
├── main.py                         # ✅ Точка входа в приложение
├── palettes.py                     # Цветовые палитры
├── music.py                        # Модуль воспроизведения музыки
├── pyproject.toml                  # Конфигурация проекта uv
├── uv.lock                         # Заблокированные версии зависимостей
├── requirements.txt                # Список зависимостей для pip
├── RUN_DONUT_CONSOLE.bat           # Быстрый запуск на Windows
├── setup.py                        # Скрипт сборки Си модуля
└── README.md                       # Документация
```

> ❗ Внимание: файлы `main_old_version.py` и `music to text.py` являются устаревшими служебными файлами и не используются в текущей версии.
